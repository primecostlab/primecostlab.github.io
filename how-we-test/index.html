How the spreadsheets are tested

The spreadsheets are not typed by hand. A program writes every formula, then a test suite opens the finished files and checks them. A file that fails one check is not released.

Restaurant Financial Toolkit and free calculator · 45 checks

Run on the master file, each preset (restaurant, bar, cafe / food truck) and the free edition.

  • Every file builds, with the sheets in the documented order
  • No result cell holds a typed number: results are formulas
  • Every input cell is light blue, so you always know what to type
  • Only functions that also work in Google Sheets are used
  • No #REF!, #DIV/0!, #VALUE! or other Excel errors, on every preset and edition
  • Each preset reproduces a hand-built control dataset within 0.5%
  • The model matches an independent reference calculation written separately in code
  • Cash rolls forward correctly from month to month and year to year
  • Sources of funds equal uses of funds in the projection
  • Switching the preset dropdown changes the defaults, and your own values always win over the preset
  • The free calculator is built as a subset of the paid model, and its dashboard values are checked
  • No benchmark number exists without a source
  • Seat turns stay reference-only, with no color, because no reliable benchmark exists
  • Money cells show thousands separators; ratios get green / yellow / red formatting
  • The support address and the README ship with every package

Bar Inventory & Pour Cost Tracker · 24 checks

  • The file opens with the expected sheets, one font, light-blue input cells and no macros
  • No Excel errors; only Google Sheets compatible functions
  • Usage = beginning + purchases − ending for every product line, and category totals add up
  • Pour cost by category and total match the control calculation
  • Cost per serving and suggested price match the recipe spec (e.g. the sample Margarita)
  • Top 5 cocktails are ranked by monthly contribution margin
  • Prime cost, yearly P&L and EBITDA match the control numbers
  • Benchmarks without a reliable source are left blank, and EBITDA shows no benchmark
  • Kegs and cases convert correctly to ounces

What the tests cannot tell you

They prove the math is consistent and error-free on realistic sample data. They cannot tell you whether your own assumptions are right: the projection is only as good as the numbers you enter. It is a planning model, not accounting, tax or legal advice.
